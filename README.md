# sosedushka
Power BI Final Project
Данный отчет показывает динамику продаж и основные показатели по магазинам (средний чек, количество продаж, прирост год к году)
	Данные взяты из базы данных торговой сети, 81 тыс. строк, продажи за 2 года, структура состоит из таблицы фактов и четырех справочников
	Данные загружены из Excel, добавлена таблица календарь, подготовлены меры: Выручка, Количество клиентов и чеков, средний чек (по карте/без карты), прирост год к году. 
	Из анализа узнал, что основные пики продаж приходятся на январь, март и июль, сильно проседают в феврале, так снижение наблюдается в сентябре. К прошлому году растут все магазины. На гистограмме магазины осортированы по выручке, видно какие приносят наибольшую выручку, выделены градиентом по приросту к прошлому году. Карты лояльности не помогают продавать больше, средний чек у таких покупателей ниже, чем у покупателей без карты.
